STUDYLAB SUPPORT WEBSITE — READ THIS FIRST

I built the website for you.

FILES
- index.html = StudyLab Support
- privacy.html = StudyLab Privacy Policy
- styles.css = design
- studylab-icon.png = your real icon
- config.js = the ONLY file you need to edit
- site.js = inserts the support email automatically

BEFORE PUBLISHING
1. Open config.js in TextEdit.
2. Replace:
   YOUR_SUPPORT_EMAIL_HERE
   with the email address you want users to contact for StudyLab support.
3. Save the file.

IMPORTANT
Apple requires the Support URL to lead to real contact information.
Do not publish the site while the placeholder email is still there.

GITHUB PAGES (simple free hosting)
1. Create/open a GitHub account.
2. Create a new PUBLIC repository named: studylab-support
3. Upload ALL files from this folder to the repository.
4. Open repository Settings.
5. Click Pages in the left sidebar.
6. Under Build and deployment:
   Source = Deploy from a branch
   Branch = main
   Folder = / (root)
7. Click Save.
8. Wait a minute or two.
9. GitHub will show the public site URL.

Your URLs will normally look like:
Support:
https://YOUR-GITHUB-NAME.github.io/studylab-support/

Privacy:
https://YOUR-GITHUB-NAME.github.io/studylab-support/privacy.html

APP STORE CONNECT
Support URL -> use the Support URL above.
App Privacy -> Privacy Policy URL -> use the Privacy URL above.

IMPORTANT APP REVIEW NOTE
Apple's App Review Guidelines also expect the privacy policy to be easily accessible INSIDE the app.
Once this website is live, add a Privacy Policy link in StudyLab Settings before the final App Review build.
